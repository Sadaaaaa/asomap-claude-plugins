# ASOMap plugins for Claude Code

A Claude Code plugin marketplace with one plugin, **asomap**: it connects your
[ASOMap](https://asomap.com) workspace — daily keyword ranks in the App Store, Google Play
and RuStore — and adds six ASO workflows that run on your real data.

```
/plugin marketplace add Sadaaaaa/asomap-claude-plugins
/plugin install asomap@asomap
```

Then ask, for example, "review my app" or "find new keywords for Germany". The first time,
Claude Code opens ASOMap to sign in; click Allow. See [the plugin's README](plugins/asomap/README.md)
for the workflows, and [asomap.com/mcp-docs](https://asomap.com/mcp-docs) for every tool.

Using Claude on the web or the desktop app? Add ASOMap from Claude's connector directory:
https://claude.ai/directory/connectors/asomap
