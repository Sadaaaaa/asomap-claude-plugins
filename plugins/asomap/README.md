# ASOMap for Claude Code

Connects your [ASOMap](https://asomap.com) workspace to Claude Code — keyword ranks in the
App Store, Google Play and RuStore — and adds six ASO workflows that run on your real data.

## Install

```
/plugin marketplace add Sadaaaaa/asomap-claude-plugins
/plugin install asomap@asomap
```

The first time a workflow needs data, Claude Code opens ASOMap to sign in (OAuth); click
Allow and it's connected. No key to copy. You need an ASOMap plan that includes MCP
(Pro or Team).

## Workflows

Ask in your own words, or name the workflow:

| Workflow | Ask for example |
|---|---|
| `app-review` | "Review my app", "how is my app doing" |
| `beat-a-competitor` | "Where is Yazio ahead of me and how do I catch up" |
| `new-keywords` | "Find new keywords for Germany" |
| `listing-for-keywords` | "Rewrite my subtitle and keyword field for my keywords" |
| `release` | "Translate these release notes into every language", "make screenshots" |
| `weekly-brief` | "Weekly ASO brief for the team" |

Workflows read your data freely. Anything that changes your workspace (tracking keywords or
competitors, saving a listing draft, release notes or a screenshot set) is proposed first and
done only when you agree. Nothing is ever published to a store.
